# 🛠️ How We Will Achieve the Requirements

This document explains the technical strategy, programming choices, and step-by-step methods our group used to fulfill every single assignment criteria item.

---

## 1. Requirements Fulfillment Matrix

| Assignment Criteria                               | Project Requirement Item                                                                | How Our Code Achieves It Safely                                                                                                                                                                                                    |
|:--------------------------------------------------|:----------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Requirement 2** <br>*(Spring Boot App)*         | Create a Spring Boot application using Java.                                            | We used Spring Initializr to create the core codebase. It runs on modern **Java 26** and **Spring Boot 4.1.0** to handle dependency injection out of the box.                                                                      |
| **Requirement 3** <br>*(REST Endpoints)*          | Use endpoints with parameters, clear response codes, and add an OpenAPI URL.            | We built `BookController` and `PurchaseController`. They use parameters like `@PathVariable` and return clean codes like `201 Created` or `204 No Content`. The Swagger URL link is added straight to our main README.             |
| **Requirement 4** <br>*(Database Integration)*    | Connect a MySQL database, save reference `.sql` scripts, and use JPA entities/repos.    | We saved our setup scripts inside `db/schema.sql` and `db/seed.sql`. We used Spring Data JPA to build clean entity models (`Book.java`) and repositories (`BookRepository.java`) to read and write records without typing raw SQL. |
| **Requirement 5** <br>*(Testing)*                 | Unit test the majority of your methods and use Mockito to mock dependencies.            | We built `BookServiceTest` and `PurchaseServiceTest` using JUnit 5 and Mockito. They mock our database repos using `@Mock` so all **19 tests pass 100% green** without needing an active database connection.                      |
| **Requirement 6** <br>*(Exceptions)*              | Handle exceptions appropriately across the application layer.                           | We created custom runtime errors (`OutOfStockException`, `DuplicateOperationException`) and built a centralized `GlobalExceptionHandler.java` file to map them to clean HTTP errors (`404` or `409`).                              |
| **Requirement 7** <br>*(Docker Containerization)* | Create a Dockerfile and a docker-compose.yaml file to run two services together.        | We wrote a `Dockerfile` to image our Java code and linked it inside `docker-compose.yaml` alongside an official **MySQL 8.4 database service container**, providing simple running commands.                                       |
| **Requirement 9** <br>*(General Spring Coding)*   | Use constructors cleanly via Lombok, add logs via `@Slf4j`, and use app configurations. | We used Lombok annotations like `@RequiredArgsConstructor` for clean injection and `@Slf4j` to write tracking statements. We stored threshold rules like `minimum-price` inside `application.yaml`.                                |
